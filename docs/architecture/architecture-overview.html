1 · Backend — Clean Architecture

barber-flow-api/Barber.Flow.Api/

La dependencia fluye hacia adentro: los siete endpoints llaman a un Service de Application, que solo conoce interfaces de Domain; MongoDB (Infrastructure) implementa esas interfaces y persiste las entidades.
